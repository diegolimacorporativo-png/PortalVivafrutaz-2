### CORREÇÃO

Mantenha Leaflet.

Mantenha CARTO como provedor de tiles por enquanto.

NÃO troque para Google Maps.

NÃO troque novamente de provedor.

### 1. SIMPLIFICAR A URL DOS TILES

A configuração atual usa:

`https://{s}.basemaps.cartocdn.com/light_all/{z}/{x}/{y}{r}.png`

REMOVA o `{r}`.

Utilize exatamente:

`https://{s}.basemaps.cartocdn.com/light_all/{z}/{x}/{y}.png`

Não utilize retina por enquanto.

### 2. CONFIGURAR O TILELAYER DE FORMA EXPLÍCITA

Garanta que o TileLayer seja criado com:

* URL correta;
* `maxZoom` compatível;
* `crossOrigin` adequado, se necessário;
* atribuição correta;
* subdomains `a`, `b`, `c` se a configuração exigir.

Não criar várias camadas.

### 3. ADICIONAR EVENTOS DE DEBUG

No TileLayer, adicionar temporariamente handlers para:

* `tileload`
* `tileerror`
* `loading`
* `load`

Quando ocorrer `tileerror`, registrar no console:

`MAP TILE ERROR:`

junto com a URL real do tile que falhou.

Quando ocorrer `tileload`, registrar:

`MAP TILE LOADED:`

junto com a URL real.

### 4. MOSTRAR DIAGNÓSTICO NA TELA

Durante o desenvolvimento, adicionar discretamente abaixo do mapa um pequeno status:

`Mapa: carregando...`

Depois:

`Mapa: tiles carregados`

ou:

`Mapa: erro ao carregar tiles`

Se houver erro, mostrar também o domínio que falhou.

Isso é TEMPORÁRIO e pode ser removido depois que o problema estiver resolvido.

### 5. TESTAR O TILE DIRETAMENTE NO COMPONENTE

Crie uma pequena verificação usando um `<img>` com uma URL REAL de tile, por exemplo um tile correspondente ao centro inicial do mapa.

O objetivo é descobrir se o navegador consegue renderizar a imagem.

Se o `<img>` conseguir mostrar o PNG mas o Leaflet não mostrar, então o problema é Leaflet/CSS.

Se nem o `<img>` conseguir mostrar, então o problema é rede/provedor/CSP.

Não assumir a causa.

### 6. VERIFICAR O DOM

Depois da inicialização, verificar:

`.leaflet-tile`

Se existirem tiles:

* verificar `src`;
* verificar `complete`;
* verificar `naturalWidth`;
* verificar `naturalHeight`.

Registrar no console:

`LEAFLET TILE COUNT: X`

`LEAFLET TILE LOADED: X`

`LEAFLET TILE FAILED: X`

### 7. SE OS TILES CARREGAREM MAS NÃO APARECEREM

Então corrigir o CSS.

Verificar especificamente:

`.leaflet-tile-pane`
`.leaflet-layer`
`.leaflet-tile-container`
`.leaflet-tile`

Garantir:

* `opacity: 1`;
* `visibility: visible`;
* `display: block`;
* dimensões corretas;
* z-index correto.

NÃO aplicar CSS global.

### 8. SE OS TILES NÃO CARREGAREM

O evento `tileerror` precisa mostrar a URL real que falhou.

Nesse caso, verificar a URL diretamente no navegador.

Se CARTO estiver bloqueado no navegador real, aí sim escolher outro provedor gratuito compatível.

Mas NÃO fazer isso sem primeiro registrar o erro real.

O mapa deve ser renderizado independentemente de existirem motoristas.

→ mapa deve aparecer normalmente.

Com 1 motorista:

→ mapa aparece + marcador.

Com vários:

→ mapa aparece + todos os marcadores.

Não condicionar a criação do mapa à existência de coordenadas.
