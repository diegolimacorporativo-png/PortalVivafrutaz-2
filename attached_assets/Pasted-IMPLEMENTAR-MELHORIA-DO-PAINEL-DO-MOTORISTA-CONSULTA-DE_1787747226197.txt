==================================================
OBJETIVO
==================================================

O motorista precisa conseguir localizar rapidamente um pedido específico de um cliente, mesmo que ele não esteja procurando pela rota.

Hoje o painel possui:

- De
- Até
- Empresa
- Buscar pedidos
- Hoje

Mas falta uma busca direta por pedido/cliente.

Adicionar um filtro:

### "Buscar pedido ou cliente"

Esse campo deve permitir localizar por:

- código do pedido;
- nome da empresa/cliente;
- CNPJ, se esse dado já estiver disponível na consulta existente.

Exemplo:

`VF-2026-000101`

ou

`Sacolão do Zé Eireli`

Manter os filtros atuais.

Não remover:

- De

Adicionar:

==================================================
COMPORTAMENTO DA BUSCA
==================================================

A busca deve funcionar em conjunto com os filtros existentes.

Exemplos:

1. Buscar:
`VF-2026-000101`

→ mostrar somente o pedido correspondente.

2. Buscar:
`Sacolão do Zé Eireli`

→ mostrar pedidos dessa empresa.

3. Buscar parcialmente:
`Zé Eireli`

→ encontrar a empresa, se a API existente suportar busca parcial.

4. Buscar código parcialmente:
`000101`

→ encontrar o pedido correspondente, se compatível com a consulta atual.

5. Campo vazio:

→ comportamento atual permanece exatamente igual.
