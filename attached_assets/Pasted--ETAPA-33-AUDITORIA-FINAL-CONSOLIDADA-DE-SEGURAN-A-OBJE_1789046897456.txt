==================================================
TRACKING — VALIDAR ESPECIALMENTE
==================================================

Confirmar novamente:

PUBLIC TOKEN:
- token válido funciona;
- token adulterado falha;
- token expirado falha;
- token cross-resource falha;
- token não expõe dados internos;
- token não permite troca de tenant;
- rate limit permanece.

NUMERIC LEGACY:
- exige sessão;
- tenant-bound só acessa própria empresa;
- cross-tenant retorna bloqueio;
- MASTER/DIRECTOR global preservados;
- consulta detalhada não ocorre antes da validação;
- anônimo não consegue usar ID numérico.

Não modificar nada.
