* Repetir uma conclusão não deve duplicar eventos.

### 3. VERIFIQUE A FINALIZAÇÃO MANUAL DE PEDIDOS

Investigue se algum endpoint, botão, formulário ou processo automático permite finalizar um pedido que ainda tenha entregas pendentes.

Se encontrar essa possibilidade, corrija-a utilizando os padrões já existentes no projeto.

Verifique pelo menos estes cenários:

1. Todas as entregas concluídas: o pedido pode ser finalizado.
2. Entregas concluídas ou canceladas, sem pendências: o pedido pode ser finalizado.
3. Existe pelo menos uma entrega pendente: a finalização deve ser bloqueada.
4. Uma entrega é cancelada: as demais mantêm seus status.
5. A mesma conclusão é enviada novamente: o histórico não é duplicado.
6. Uma operação falha: os dados não ficam parcialmente atualizados.
