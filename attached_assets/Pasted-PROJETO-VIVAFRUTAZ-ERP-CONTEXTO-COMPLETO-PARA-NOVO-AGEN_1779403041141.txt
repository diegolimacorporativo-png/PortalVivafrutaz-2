====================================================================
REGRA ABSOLUTA DE DADOS
====================================================================

TODO dado persistente DEVE salvar no Supabase.

É PROIBIDO:
- usar banco interno do Replit
- persistir estado crítico apenas em memória
- usar mocks permanentes
- usar fallback local silencioso
- sobrescrever estado do usuário no boot

Problema crítico já resolvido anteriormente:
o sistema sobrescrevia senhas no boot via unlockStrategicAccounts().
Isso foi removido.

Hoje:
- senhas persistem corretamente no Supabase
- qualquer alteração de senha DEVE sobreviver restart/deploy

====================================================================
MULTI-TENANT
====================================================================

O sistema é multi-tenant REAL.

Regras críticas:

- isolamento tenant obrigatório
- fail-closed
- AsyncLocalStorage TenantContext
- requireTenantId()
- jamais vazar dados cross-tenant
- jamais remover proteções tenant
- toda query deve respeitar empresa/company_id
