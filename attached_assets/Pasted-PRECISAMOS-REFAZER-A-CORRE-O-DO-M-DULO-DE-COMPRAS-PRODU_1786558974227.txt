5. ERRO DE SUBCATEGORIA
========================

Existe este erro ao salvar produto:

500:

update or delete on table "product_sub_categories" violates foreign key constraint
"order_items_sub_category_id_product_sub_categories_id"
on table "order_items"

O fluxo identificado anteriormente foi:

ProductModal.tsx
→ updateProduct.mutateAsync(...)
→ DELETE /api/products/{id}/subcategories
→ ProductController.deleteAllSubCategoriesForProduct()
→ ProductService.removeAllSubCategoriesForProduct()
→ ProductRepository.deleteSubCategoriesByProductId()
→ storage.deleteProductSubCategoriesByProductId()
→ DELETE product_sub_categories

O problema é:

existem order_items apontando para determinadas subcategorias.

Portanto, apagar todas as subcategorias durante uma simples edição do produto quebra a FK.

NÃO faça cascade delete.
NÃO remova a foreign key.
NÃO apague order_items.
NÃO faça alteração destrutiva no banco.

A solução deve preservar histórico dos pedidos.

Primeiro determine qual é o comportamento correto para editar subcategorias que já estão sendo utilizadas por pedidos.
