==================================================================
PADRÃO OBRIGATÓRIO DE CORREÇÃO
==================================================================

Substituir padrões inseguros por:

OPTIONAL CHAINING:
obj?.prop?.value

NULLISH FALLBACK:
value ?? 0

DEFAULT OBJECTS:
const data = response || {}

DEFAULT ARRAYS:
const items = response?.items || []

SAFE DESTRUCTURING:
const {
  resumo = { total: 0 },
  erros = [],
} = diagnostic || {}

SAFE MAP:
(items || []).map(...)

SAFE LENGTH:
(items?.length ?? 0)
